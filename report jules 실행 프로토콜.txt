### 🚀 첫 번째 AI 투자 조언서 뽑아내기 (Jules 연동 워크플로우)

#### 1단계: 로컬에서 최신 데이터 스냅샷 만들기

1. RStudio 화면에서 방금 저장하신 **`agent_finace_260709.R`** 파일을 엽니다.
2. 스크립트 전체를 실행(`Source` 버튼 클릭 또는 전체 선택 후 `Run`)합니다.
3. 스크립트가 1~2단계(OCR 및 지표 크롤링)만 수행한 뒤 깔끔하게 종료되며, 폴더 안에 `realtime_snapshot.txt`라는 파일이 새로 생성되었는지 확인합니다.

#### 2단계: 최신 스냅샷을 깃허브에 업로드하기

방금 뽑아낸 따끈따끈한 실시간 데이터를 Jules가 읽을 수 있도록 깃허브에 올려줍니다. 터미널 창에 아래 세 줄을 입력합니다.

```bash
git add .
git commit -m "최신 포트폴리오 데이터 스냅샷 생성"
git push

```

*(참고: 만약 이전 답변에서 안내해 드렸던 `JULES.md` 파일(투자 지침 룰북)을 아직 안 만드셨다면, 메모장이나 RStudio에서 마크다운 파일을 하나 만드셔서 폴더에 넣은 뒤 위 명령어로 같이 업로드해 주셔야 Jules가 똑똑하게 룰을 따릅니다.)*

#### 3단계: Jules 대시보드에서 에이전트 가동하기

이제 RStudio는 잠시 내려두고, 거대한 추론 연산을 구글 서버에 위임할 차례입니다.

1. 웹 브라우저를 열고 **[jules.google.com](https://jules.google.com)** 에 접속합니다. (Gemini Pro 구독 중인 구글 계정 사용)
2. 초기 화면에서 GitHub 계정 연동(Sync)을 진행한 뒤, 방금 파일을 올린 **`LeeYeonDong/portpolio`** 레포지토리를 선택합니다.
3. Jules의 대화창(프롬프트 입력창)에 아래의 지시를 복사해서 그대로 붙여넣고 전송합니다.

> 🗣️ **Jules 입력 프롬프트:**
> `"내 저장소에 방금 업데이트된 realtime_snapshot.txt 파일의 데이터를 읽어줘. 그리고 저장소에 있는 투자 규칙(JULES.md)과 7단계 프로토콜을 100% 준수하여, Agent A(공격적)와 Agent B(보수적)의 내부 토론 및 Judge Chat의 조율 과정을 시뮬레이션해 줘. 시뮬레이션이 끝나면 최종 합의된 조언서 결과를 'Final_Execution_Report_Debate.md'라는 파일로 작성해서 내 저장소에 Pull Request(또는 Commit)로 올려줘."`

이 명령을 내리면 Jules가 스스로 계획(Plan)을 세우고 사용자에게 승인을 요청할 것입니다. 'Approve'를 눌러주시면 Jules가 구글 클라우드 환경에서 알아서 방대한 금융 데이터를 분석하고 최종 마크다운 리포트 문서를 깃허브에 생성해 줍니다.
