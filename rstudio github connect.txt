오랜만에 깃허브(GitHub)를 사용하시면 바뀐 인증 방식 때문에 충분히 헷갈리실 수 있습니다. 특히 요즘 깃허브는 보안 정책상 터미널에 **계정 비밀번호를 직접 입력하면 로그인 오류**가 납니다.

RStudio 환경에서 로컬 폴더(`D:/대학원/portpolio`)를 깃허브에 완벽하게 연동하는 가장 쉽고 확실한 단계를 알려드릴게요. RStudio 하단의 **Terminal** 탭을 열고 그대로 따라 하시면 됩니다.

---

### 1단계: 깃허브 웹사이트에서 저장소 생성

1. [GitHub](https://github.com/)에 로그인한 뒤, 오른쪽 상단의 **[+]** 버튼 ➡️ [New repository]를 클릭합니다.
2. **Repository name**에 프로젝트 이름(예: `portpolio`)을 입력합니다.
3. ⚠️ **[중요]** 아래쪽에 있는 README, .gitignore, License 추가 체크박스는 모두 체크하지 않은 상태(None)로 둡니다. 로컬에 이미 파일이 많기 때문에 여기서 파일을 만들면 충돌이 납니다.
4. [Create repository]를 누르면 저장소가 만들어지며, 화면에 주소가 뜹니다. **HTTPS 탭**이 선택된 상태에서 주소(예: `[https://github.com/유저ID/portpolio.git](https://github.com/유저ID/portpolio.git)`)를 복사해 둡니다.

---

### 2단계: RStudio 터미널 설정 및 첫 커밋 (Commit)

RStudio의 **Terminal** 탭(Console 탭 옆)으로 이동합니다. 이미 해당 프로젝트 폴더 경로로 지정되어 있을 것입니다.

**① 오랜만이니 Git 사용자 등록부터 확인합니다.**

```bash
git config --global user.name "본인의 깃허브 닉네임"
git config --global user.email "본인의 깃허브 가입 이메일"

```

**② 로컬 폴더를 Git 저장소로 초기화하고 파일을 담습니다.**

```bash
# 1. 현재 폴더를 Git 저장소로 선언
git init

# 2. 폴더 내 모든 파일을 올릴 준비 (Staging)
git add .

# 3. 첫 박제(버전 저장) 및 메시지 작성
git commit -m "First portfolio commit"

# 4. 기본 브랜치 이름을 main으로 변경 (요즘 트렌드)
git branch -M main

```

---

### 3단계: 깃허브 원격 저장소 연결 및 업로드 (Push)

이제 1단계에서 복사해 둔 깃허브 주소를 로컬 저장소에 알려주고 업로드할 차례입니다.

```bash
# 1. 원격 주소를 'origin'이라는 이름으로 등록 (복사한 주소를 넣어주세요)
git remote add origin https://github.com/유저ID/portpolio.git

# 2. 연결 확인 (origin 주소가 잘 뜨면 성공)
git remote -v

# 3. 깃허브 main 브랜치로 파일 업로드
git push -u origin main

```

---

### 🚨 4단계: 인증하기 (가장 중요!)

`git push` 명령어를 입력하면 인증 창이 나타납니다. 여기서 예전 기억대로 계정 비밀번호를 입력하면 무조건 막힙니다. 보통 아래의 두 가지 상황 중 하나로 진행됩니다.

* **상황 A: 웹 브라우저 인증 창이 뜨는 경우 (추천)**
최신 Git 시스템이 깔려 있다면 "Sign in with your browser"라는 팝업 창이나 안내가 뜹니다. 버튼을 누르면 인터넷 브라우저 창이 열리면서 클릭 몇 번으로 연동이 간단하게 완료됩니다.
* **상황 B: 터미널에서 Password(또는 토큰)를 요구하는 경우**
팝업이 뜨지 않고 터미널창에 `Password for '[https://github.com](https://github.com)...':`라고 뜨면 개인 액세스 토큰(PAT)을 입력해야 합니다.
1. 깃허브 웹사이트 우측 상단 프로필 클릭 ➡️ **Settings** 이동
2. 왼쪽 최하단 **Developer Settings** ➡️ **Personal access tokens** ➡️ **Tokens (classic)** 클릭
3. **Generate new token (classic)** 클릭 후 노란색 `repo` 항목에 체크하고 맨 아래에서 토큰 생성
4. 화면에 생성된 **`ghp_...`로 시작하는 긴 문자열을 복사**한 뒤, RStudio 터미널의 **Password 자리에 그대로 붙여넣기(오른쪽 마스크 클릭 혹은 Ctrl+V 후 엔터)** 하시면 됩니다. (보안상 타이핑해도 화면에는 아무 글자도 안 보이니 그냥 붙여넣고 엔터 치시면 됩니다!)



---

이렇게 한 번 성공하고 나면, 다음부터는 RStudio에서 데이터를 새로 뽑았을 때 터미널에 딱 세 줄만 치면 깃허브에 실시간으로 동기화됩니다.

```bash
git add .
git commit -m "데이터 최신화"

```

아, 윈도우 기본 설정 때문에 '문서' 폴더가 OneDrive 경로(`~/OneDrive/문서`)로 강제 지정되어 있어서 그렇습니다.

데이터 분석이나 AI 에이전트(Jules, Claude Code 등)를 구동할 때 OneDrive 경로는 파일 동기화 락(Lock)이나 한글 경로 깨짐 오류를 유발할 수 있으므로, **실제 작업 공간인 `D:/대학원/portpolio`로 터미널 시작 주소를 변경해 주시는 것이 훨씬 안전하고 좋습니다.**

상황에 맞게 주소를 바꾸는 3가지 방법을 정리해 드립니다.

---

### 1. [가장 추천] RStudio 프로젝트(.Rproj) 활용하기

RStudio는 **'프로젝트'** 단위를 열면 터미널 주소가 자동으로 해당 프로젝트 폴더로 변경됩니다. 매번 직접 폴더를 찾아갈 필요가 없어 가장 깔끔한 방법입니다.

1. RStudio 우측 상단의 **[Project: (None)]** 단추(또는 메뉴의 `File` ➡️ `New Project...`)를 클릭합니다.
2. [Existing Directory]를 선택합니다.
3. `Browse`를 눌러 현재 작업 중인 **`D:/대학원/portpolio`** 폴더를 선택하고 [Create Project]를 누릅니다.
4. 이제 프로젝트가 활성화되면서, 터미널을 새로 열 때(`Shift + Alt + T` 또는 Terminal 탭 닫고 새로 열기) 자동으로 주소가 `D:/대학원/portpolio`로 잡히게 됩니다.

---

### 2. RStudio 기본 작업 디렉토리(Working Directory) 변경하기

프로젝트 기능을 쓰지 않더라도, RStudio가 처음 켜질 때 열리는 기본 폴더 자체를 OneDrive가 아닌 D드라이브로 고정하는 방법입니다.

1. RStudio 상단 메뉴에서 **`Tools`** ➡️ `Global Options...`로 들어갑니다.
2. **`General`** 탭의 최상단에 있는 **`Default working directory (when not in a project):`** 항목을 찾습니다.
3. **`Browse...`** 버튼을 눌러 `D:/대학원/portpolio`를 선택합니다.
4. **[Apply]** ➡️ [OK]를 누른 뒤 RStudio를 완전히 껐다 켜면 터미널 기본 주소가 바뀝니다.

---

### 3. 터미널 설정 확인하기 (옵션)

위의 설정을 했는데도 안 바뀐다면 터미널 자체 세부 옵션을 확인해야 합니다.

1. **`Tools`** ➡️ **`Global Options...`** ➡️ **`Terminal`** 탭으로 이동합니다.
2. 중간에 있는 **`New terminals open with:`** 설정이 **[Project directory]** 또는 [Current R working directory]로 되어 있는지 확인하고, 아니라면 둘 중 하나로 변경해 줍니다.

---

### 💡 [참고] 현재 터미널에서 명령어로 즉시 이동하기

지금 당장 터미널에서 주소를 바꾸고 싶다면 아래 명령어를 입력하시면 됩니다. 현재 켜져 있는 터미널이 **Git Bash(MINGW64)** 기반이기 때문에 리눅스 스타일로 드라이브 명을 입력해야 합니다.

```bash
cd /d/대학원/portpolio

```

*(주의: `cd D:\대학원...` 처럼 백슬래시(`\`)를 쓰면 Git Bash에서 경로 인식을 못 하거나 에러가 날 수 있으니 위와 같이 슬래시(`/`)를 사용해 주세요.)*
